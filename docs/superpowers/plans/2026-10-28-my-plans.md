# My Plans Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shared My Plans library: write plans, bring in PDFs / photos / scans / web pages that are read offline and drafted into steps and a cut list for review, and print a step-by-step build guide; kid-friendly plans appear on the kids' side.

**Architecture:** Pure drafting rules in `src/plans/draft.ts` turn positioned text lines into a draft plan. The main process owns plan folders (`electron/plansStore.ts`), OCR (`electron/ocr.ts`, tesseract.js with bundled English data) and web capture. The renderer reads PDFs with pdf.js (text with positions, page images) and drives a zustand store (`src/plans/plansStore.ts`) and the screens under `src/plans/ui/`.

**Tech Stack:** Electron 45, React 18, TypeScript strict, Tailwind, zustand, tesseract.js 7.0.0 + @tesseract.js-data/eng 1.0.0 (4.0.0_best_int), pdfjs-dist 6.4.299, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-28-my-plans-design.md`

## Global Constraints

- Inches only; metric in imports converted to the nearest 1/32" and flagged `check me — converted from metric`.
- No network except loading a web page during import (30 s limit). OCR language data ships with the app.
- Plans folder: `<Documents>/A&A Woodworking/Plans/<plan name>/` with `plan.json` (formatVersion 1), `pages/page-001.png…`, `photos/<id>.jpg` (long side ≤ 1600), `design.aaw`.
- Saves use `safeSave`; damaged `plan.json` falls back to `.bak`.
- A PDF page with fewer than 20 text characters is treated as a scan (OCR). PDF pages render at 150 dpi.
- OCR words under 60% confidence are uncertain; any number containing one is flagged, never guessed.
- Kids' side lists only `kidFriendly` plans, hides New / Bring in / editing, and marks "Adult does this" with `adultDoes`.

## Review Focus

1. OCR's `2-3/4x11-1/4x 9" Sides` (the "2 - " qty dash eaten) must draft as qty 2 of 3/4 × 11-1/4 × 9, flagged — pinned in Task 1.
2. Cancelling an import halfway must leave no plan folder behind — pinned in Task 2.
3. A plan name with `\ / : * ? " < > |` or one that already exists must still save to a valid, unique folder — pinned in Task 2.
4. A kid-friendly plan's step using a tool above his tier shows "Adult does this"; an Adult plan never lists on the kids' side — pinned in Task 6.
5. A plan whose attached design file was deleted still opens and shows its cut list — pinned in Task 2.
